OpenGL 3D Rendering Engine

This project is a 3D rendering/game engine that abstracts most of the complicated OpenGL configurations to direct focus on developing and rendering a 3D scene. Features are still being added with the most recent being texture filtering.

Requirements:
- System must be able to run OpenGL 4.6
- Must have GLFW/GLAD installed to run as this project was all compiled using vscode

Project is free to use for those who wish to try developing something with it
